## Подготовка

1. Открыть последний зелёный прогон:
   <https://github.com/TDots9791/Sphaera-Commander-Win64/actions>
2. Скачать артефакты:
   - `SphaeraCommander-win64-setup` → `.msi` — установщик;
   - `SphaeraCommander-win64` → `.zip` — портативная версия.

## Установка (MSI)

- [ ] MSI ставится двойным кликом; визард на русском; лицензия MIT в визарде
- [ ] выбор каталога установки работает (кнопка «Обзор»)
- [ ] после установки: ярлыки «Пуск» и на рабочем столе; у exe фирменная иконка (весы)
- [ ] PT Serif установлен: `C:\Windows\Fonts\PT_Serif-Web-Regular.ttf` существует
- [ ] «О программе» отрисован фирменным serif (не системным суррогатом)
- [ ] в контекстном меню проводника на папке есть «Открыть в Sphaera Commander» — папка открывается в приложении

## Приложение

- [ ] старт с чистым конфигом; обе панели; тема тёмная Iustitia по умолчанию
- [ ] темы: Вид → Тема — тёмная/светлая/системная применяются
- [ ] навигация: кнопка дисков 💾, Alt+F1/F2, история Alt+←/→/↓
- [ ] F3: текст, md, json (дерево), pdf (страницы, аннотации), docx, xlsx (правка + формулы), pptx, fb2/epub
- [ ] F4: правка текста; md — живой предпросмотр; xlsx — сетка с формулами и Ctrl+S
- [ ] F5/F6 копирование/перенос; диалог перезаписи при конфликте
- [ ] **F8 — удаление в корзину: файл реально в Recycle Bin и ВОССТАНАВЛИВАЕТСЯ оттуда** (главный пункт Ф3)
- [ ] Shift+F8 — безвозвратно, с явным вопросом
- [ ] архивы как каталоги (VFS): zip, 7z; распаковка/запаковка; чтение RAR (положить `unrar.exe` рядом или в PATH)
- [ ] кириллические имена файлов и папок везде (в т.ч. в архивах)
- [ ] поиск Alt+F7 по содержимому; фильтры размера/даты
- [ ] групповое переименование; сравнение каталогов (в т.ч. по хэшу)
- [ ] временная панель: собрать из разных мест → копировать/перенести
- [ ] Ctrl+A — файлы; двойное Ctrl+A — файлы+каталоги
- [ ] вкладки Ctrl+T/W; переживают перезапуск
- [ ] командная строка внизу: cmd.exe-синтаксис, кириллический вывод, пути с пробелами
- [ ] кнопки панели: `%f`/`%d` с путями-с-пробелами (кавычки cmd!)
- [ ] «Открыть терминал здесь»: wt / PowerShell / cmd — проверить флаги всех трёх
- [ ] **тачпад-щипок (zoom) в быстром просмотре и F3/F4** — на Windows жест приходит иначе; запасной путь Ctrl+колесо
- [ ] шифрование (если поставлен Gpg4win): gpg-раундтрип `.gpg`; age по ключу
- [ ] плагины: «Инструменты → Плагины…», включение после перезапуска, сломанный не роняет
- [ ] языки: Вид → Язык — Русский/English/中文 (после перезапуска)

## Обновление

- [ ] запустить тот же MSI поверх установленного — настройки переживают
      (заранее: добавить кнопку в buttonbar и пункт в Hotlist)

## Деинсталляция

- [ ] «Параметры → Приложения» → удалить — без вопросов и мусора
- [ ] каталог установки, ярлыки, ассоциация папок, шрифт PT Serif — удалены
- [ ] конфиг `%APPDATA%\SphaeraCommander` ОСТАЁТСЯ (осознанно); при полном
      сносе удалить вручную

## Портативная версия

- [ ] zip распаковывается в произвольный каталог, запускается без установки
- [ ] настройки портативной не конфликтуют с установленной версией
